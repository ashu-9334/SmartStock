
# SmartStock – Inventory and Sales Management System

SmartStock is a C-based inventory and sales management system with a web dashboard.

## Features
- View product inventory
- Track available stock
- Process product sales
- Automatically update stock after a sale
- View sales and revenue statistics
- Interactive web dashboard

## Technologies Used
- C
- HTML
- CSS
- JavaScript
- Python Flask

## How to Run
1. Open the project folder in VS Code.
2. Compile the C bridge:
   `clang -Wall -Wextra web_bridge.c -o web_bridge`
3. Start the backend:
   `python3 backend/app.py`
4. Open the frontend dashboard in your browser.
